Building 1D Rydberg Crystals

The following notebook shows a study of many-body dynamics on a 1D system. It is based on 1707.04344 (external). The authors of that paper studied the preparation of symmetry-breaking states in antiferromagnetic Ising chains, by tuning the interaction and driving parameters accross the phase diagram. In this notebook, we reproduce some results of this paper. Since this is a particular experiment not based on certified devices, we will use the MockDevice class to allow for a wide range of configuration settings.

1. Rydberg Blockade at Resonant Driving

Section titled “1. Rydberg Blockade at Resonant Driving”

We first consider clusters of 1,21, 21,2 and 333 atoms under resonant (δ=0\delta = 0δ=0) driving. If all the atoms are placed within each other’s blockade volume, only one excitation per group will be possible at a time. The Rabi frequency will be enhanced by N\sqrt{N}N​

Given a value of the maximum Rabi Frequency applied to the atoms, we can calculate the corresponding blockade radius using the rydberg_blockade_radius() method from MockDevice. We use this to arrange clusters of atoms which will experience this blockade effect:
