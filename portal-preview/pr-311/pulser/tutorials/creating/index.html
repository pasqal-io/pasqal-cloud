Tutorial: Programming with Pulser

This tutorial demonstrates how to use Pulser to program the evolution of a quantum system. Two programs are presented:

  • In a first part, we excite one atom from its ground state to its excited state using a constant pulse.

  • In a second part, we show how to prepare a quantum system of 9 atoms in an anti-ferromagnetic state using time-dependent pulses.

This tutorial follows the step-py-step guide on how to create a quantum program using Pulser that is provided in the programming page. For more information regarding the steps followed and the mathematical objects at stake, please refer to this page.

Preparing an atom in the Rydberg state

Section titled “Preparing an atom in the Rydberg state”

As presented in “Programming a neutral-atom QPU”, Pulser enables you to program an Hamiltonian composed of an interaction Hamiltonian and a drive Hamiltonian.

Let’s program this Hamiltonian HHH such that an atom initially in the ground state ∣g>\left|g\right>∣g⟩ is measured in the Rydberg state ∣r>\left|r\right>∣r⟩ after a time Δt\Delta tΔt.

Since we are working with a single atom, there is no interaction Hamiltonian. In this specific example, H=HDH=H^DH=HD. For a simple pulse having a duration Δt\Delta tΔt, a constant amplitude along time Ω\OmegaΩ, detuning δ=0\delta=0δ=0 and phase ϕ=0\phi=0ϕ=0 the Hamiltonian between 0 and Δt is:

H(t)=ℏΩ2(∣g⟩⟨r∣+∣r⟩⟨g∣)H(t) = \hbar\frac{\Omega}{2} (|g\rangle\langle r| + |r\rangle\langle g|)H(t)=ℏ2Ω​(∣g⟩⟨r∣+∣r⟩⟨g∣)

To find the atom in the Rydberg state at the end of the program, we want ΩΔt=π\Omega \Delta t = \piΩΔt=π so we choose Δt=1000 ns\Delta t=1000\ nsΔt=1000 ns and Ω=π rad/μs\Omega=\pi\ rad/\mu sΩ=π rad/μs.

  • We can use the Bloch sphere representation

    The pulse being of duration Δt\Delta tΔt, of detuning δ=0\delta=0δ=0, of phase ϕ=0\phi=0ϕ=0 and constant amplitude Ω\OmegaΩ, the pulse will make the vector representing the state rotate by an angle ΩΔt\Omega \Delta tΩΔt around the axis (1,0,0)(1, 0, 0)(1,0,0). To go from the ground state ∣g>\left|g\right>∣g⟩ to the excited state ∣r>\left|r\right>∣r⟩ by rotating around the (1,0,0)(1, 0, 0)(1,0,0) axis, we need to make a rotation of angle π\piπ.

    Therefore we get that the final state will be the Rydberg state if ΩΔt=π\Omega \Delta t = \piΩΔt=π. From this condition, we choose Δt=1000 ns\Delta t = 1000\ nsΔt=1000 ns and Ω=π rad/μs\Omega=\pi\ rad/\mu sΩ=π rad/μs.

  • We can compute the final state knowing the initial state

    The initial state being the ground state and the Hamiltonian HHH being constant along time, the final state is:

    ∣Ψf>=e−iℏHΔt∣g>=(cos⁡(Ω2Δt)(∣g⟩⟨g∣+∣r⟩⟨r∣)−isin⁡(Ω2Δt)(∣g⟩⟨r∣+∣r⟩⟨g∣))∣g>=cos⁡(Ω2Δt)∣g>−isin⁡(Ω2Δt)∣r>\begin{split}\begin{align} \left|\Psi_f\right> &= e^{-\frac{i}{\hbar} H \Delta t} \left|g\right> \\ &= \left(\cos\left(\frac{\Omega}{2} \Delta t\right)(|g\rangle\langle g| + |r\rangle\langle r|) - i \sin\left(\frac{\Omega}{2} \Delta t\right)(|g\rangle\langle r| + |r\rangle\langle g|)\right)\left|g\right>\\ &= \cos\left(\frac{\Omega}{2} \Delta t\right)\left|g\right> - i \sin\left(\frac{\Omega}{2} \Delta t\right)\left|r\right> \end{align}\end{split}∣Ψf​⟩​=e−ℏi​HΔt∣g⟩=(cos(2Ω​Δt)(∣g⟩⟨g∣+∣r⟩⟨r∣)−isin(2Ω​Δt)(∣g⟩⟨r∣+∣r⟩⟨g∣))∣g⟩=cos(2Ω​Δt)∣g⟩−isin(2Ω​Δt)∣r⟩​​​

    The final state will be the Rydberg state ∣r>\left|r\right>∣r⟩ if Ω2Δt=π2\frac{\Omega}{2} \Delta t = \frac{\pi}{2}2Ω​Δt=2π​. From this condition, we choose Δt=1000 ns\Delta t = 1000\ nsΔt=1000 ns and Ω=π rad/μs\Omega=\pi\ rad/\mu sΩ=π rad/μs.

When running an experiment on a neutral-atom QPU, the output of the quantum program is the sampling of the final state. It is a dictionary associating to each measured state the number of times it was measured.

Counter({'1': 1000})

When measuring in the ground-rydberg basis, the ground state is labelled “0” and the rydberg state “1”. For each of the 1000 measurements we did, the atom was measured in the Rydberg state, which means we designed our quantum program correctly!

Adiabatic preparation of an Anti-Ferromagnetic State

Section titled “Adiabatic preparation of an Anti-Ferromagnetic State”

Let’s now program the Ising Hamiltonian such that a set of 9 atoms initially in the ground state ∣ggggggggg>\left|ggggggggg\right>∣ggggggggg⟩ are prepared in an antiferromagnetic state ∣rgrgrgrgr>\left|rgrgrgrgr\right>∣rgrgrgrgr⟩.

To reach the desired antiferromagentic state, we can take advantage of the adiabatic theorem (external). The idea is to use a time-dependent Hamiltonian that changes slowly so that the system stays in its ground state. Therefore, we must choose a final Hamiltonian that has the antiferromagnetic state as its ground state.

This final Hamiltonian should simultaneously favor having the largest number of atoms in the ∣r>\left|r\right>∣r⟩ state (by having δ>0\delta > 0δ>0) and discourage nearest neighbors from being both in ∣r>\left|r\right>∣r⟩ (via the interaction Hamiltonian). When these contributions are appropriately balanced, we get an Hamiltonian with ∣rgrgrgrgr>\left|rgrgrgrgr\right>∣rgrgrgrgr⟩ as its ground state.

Let’s follow the protocol from this paper (external), where we define the parameters with respect to the interaction strength between nearest neighbours, UUU (see Table 1 of the paper):

U=2π rad/μsΩmax=2Uδ0=−6Uδf=2Utrise=252 ns, tfall=500 nstsweep=δf−δ0[rad⋅μs−1]2π⋅10 [rad⋅μs−2]\begin{split}U = 2\pi\ rad/\mu s\\ \Omega_{max} = 2 U\\ \delta_0 = -6 U\\ \delta_f = 2U\\ t_{rise} = 252\ ns,\ t_{fall} = 500\ ns\\ t_{sweep} = \frac{\delta_f - \delta_0 [rad\cdot\mu s^{-1}]}{2 \pi \cdot 10\ [rad\cdot\mu s^{-2}]}\end{split}U=2π rad/μsΩmax​=2Uδ0​=−6Uδf​=2Utrise​=252 ns, tfall​=500 nstsweep​=2π⋅10 [rad⋅μs−2]δf​−δ0​[rad⋅μs−1]​​

and define Ω(t)\Omega(t)Ω(t) and δ(t)\delta(t)δ(t) over time as (see Figure 1 (b)):

The Hamiltonian we are implementing is (the phase is constant and equal to 000 over time):

H=ℏ∑i(Ω(t)2(∣g⟩⟨r∣+∣r⟩⟨g∣)−δ(t)∣r⟩⟨r∣+∑j<iUijn^in^j)H = \hbar \sum_i \left (\frac{\Omega(t)}{2} \left(|g\rangle\langle r| + |r\rangle\langle g|\right) - \delta(t) |r\rangle\langle r| + \sum_{j<i}U_{ij}\hat{n}_i \hat{n}_j \right)H=ℏi∑​(2Ω(t)​(∣g⟩⟨r∣+∣r⟩⟨g∣)−δ(t)∣r⟩⟨r∣+j<i∑​Uij​n^i​n^j​)

where Uij=C6ℏRij6U_{ij} = \frac{C_6}{\hbar R_{ij}^6}Uij​=ℏRij6​C6​​.
