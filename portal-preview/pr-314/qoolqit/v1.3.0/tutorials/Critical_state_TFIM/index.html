Preparing the TFIM critical state

In this tutorial, we show how to prepare the TFIM critical ground state on a ring of N=12N = 12N=12 atoms using qoolqit's Rydberg analog model. We will:

  1. Set up a circular register and map the TFIM parameters to Rydberg drive parameters.
  2. Design a quasi-adiabatic sweep schedule.
  3. Compute the exact ground state via exact diagonalization (ED) as a reference.
  4. Run the adiabatic preparation with the emu_sv state-vector backend and compare against the ED target using fidelity, occupation, and correlation functions.

The Transverse-Field Ising Model

Section titled “The Transverse-Field Ising Model”

The one-dimensional Transverse-Field Ising Model (TFIM) is one of the most studied quantum many-body systems. Its Hamiltonian reads

HTFIM=J∑⟨i,j⟩σizσjz  +  h∑iσix H_{\text{TFIM}} = J\sum_{\langle i,j\rangle} \sigma^z_i \sigma^z_j \;+\; h\sum_i \sigma^x_i HTFIM​=J⟨i,j⟩∑​σiz​σjz​+hi∑​σix​

where σiα\sigma^\alpha_iσiα​ are the Pauli matrices for α∈{x,y,z}\alpha \in \{x,y,z\}α∈{x,y,z}. At the critical point h=Jh = Jh=J, the system undergoes a quantum phase transition between an antiferromagnetic phase (h<Jh < Jh<J) and a paramagnetic phase (h>Jh > Jh>J). The ground state at criticality exhibits long-range entanglement and algebraically-decaying correlations — signatures that make it a demanding benchmark for quantum state preparation.

From the Rydberg Hamiltonian to the Ising model

Section titled “From the Rydberg Hamiltonian to the Ising model”

We start from the Rydberg Hamiltonian with a time-dependent drive, in adimensional units:

H(t)=∑i<jJij ninj+∑i[Ω(t)2σix−δ(t) ni], H(t) = \sum_{i<j} J_{ij}\, n_i n_j + \sum_i \left[ \frac{\Omega(t)}{2}\sigma^x_i - \delta(t)\, n_i \right], H(t)=i<j∑​Jij​ni​nj​+i∑​[2Ω(t)​σix​−δ(t)ni​],

where ni=12(I+σiz)n_i = \tfrac{1}{2}(I + \sigma^z_i)ni​=21​(I+σiz​) is the Rydberg number operator on atom iii, Jij=rij−6J_{ij} = r_{ij}^{-6}Jij​=rij−6​ is the van der Waals interaction strength, Ω(t)\Omega(t)Ω(t) is the Rabi frequency, and δ(t)\delta(t)δ(t) is the detuning.

To connect this to a spin model, we substitute ni→12(I+σiz)n_i \to \tfrac{1}{2}(I+\sigma^z_i)ni​→21​(I+σiz​) everywhere. The interaction term ninjn_in_jni​nj​ expands into an Ising coupling σizσjz\sigma^z_i\sigma^z_jσiz​σjz​, plus terms linear in each σiz\sigma^z_iσiz​ (since every atom feels the sum of its interactions with all other atoms), plus a constant. The detuning term similarly splits into a σiz\sigma^z_iσiz​ piece and a constant. Collecting everything:

H(t)=∑i<jJij4σizσjz+∑i[Ω(t)2σix−12(δ(t)−hiz)σiz]+(∑i<jJij4−Nδ(t)2)I, H(t) = \sum_{i<j} \frac{J_{ij}}{4}\sigma^z_i\sigma^z_j + \sum_i \left[ \frac{\Omega(t)}{2}\sigma^x_i - \frac{1}{2}\big(\delta(t) - h^z_i\big)\sigma^z_i \right] + \left(\sum_{i<j} \frac{J_{ij}}{4} - \frac{N\delta(t)}{2}\right) I, H(t)=i<j∑​4Jij​​σiz​σjz​+i∑​[2Ω(t)​σix​−21​(δ(t)−hiz​)σiz​]+(i<j∑​4Jij​​−2Nδ(t)​)I,

where NNN is the total number of atoms, and

hiz≡∑j≠iJij2 h^z_i \equiv \sum_{j\neq i} \frac{J_{ij}}{2} hiz​≡j=i∑​2Jij​​

is a residual local longitudinal field: each atom feels an effective detuning shift coming from its interaction with every other atom in the register. The last term is a global, state-independent energy offset — it contributes only an overall phase to the dynamics, so it can be dropped for state-preparation purposes, but we keep it here explicitly for completeness.

This is precisely the (long-range, site-dependent-field) transverse-field Ising Hamiltonian. Tuning Ω(t)\Omega(t)Ω(t) and δ(t)\delta(t)δ(t) lets us drive the system toward the critical point of this Ising model, whose ground state is the target state for this tutorial.

1. Setup and imports

Section titled “1. Setup and imports”

We begin by importing the necessary modules. Beyond the core qoolqit building blocks (Drive, Register, QuantumProgram, …), we use the emu_sv backend which provides exact state-vector propagation, ideal for small systems like N=12N = 12N=12 where the full Hilbert space is accessible.

2. Building the Register

Section titled “2. Building the Register”

We place NNN atoms on a circle using Register.circle, with the nearest-neighbor spacing normalized to r=1r=1r=1. Because the Rydberg interaction decays steeply, Jij=rij−6J_{ij} = r_{ij}^{-6}Jij​=rij−6​, next-nearest-neighbor couplings are already tiny compared to nearest-neighbor ones. For NNN atoms on a circle, this ratio has a simple closed form:

Ji,i+1Ji,i+2=[2cos⁡(π/N)]6, \frac{J_{i,i+1}}{J_{i,i+2}} = \big[2\cos(\pi/N)\big]^{6}, Ji,i+2​Ji,i+1​​=[2cos(π/N)]6,

which for our N=12N=12N=12 register is ≈52\approx 52≈52 and is negligible, and farther neighbors decay even faster. This lets us collapse the all-to-all interaction sum down to nearest neighbors only:

∑i<jJij σizσjz  ≈  ∑iσizσi+1z, \sum_{i<j} J_{ij}\,\sigma^z_i\sigma^z_j \;\approx\; \sum_i \sigma^z_i \sigma^z_{i+1}, i<j∑​Jij​σiz​σjz​≈i∑​σiz​σi+1z​,

with the periodic identification σN+1z≡σ1z\sigma^z_{N+1}\equiv \sigma^z_1σN+1z​≡σ1z​ coming from the circle's closed topology, exactly the nearest-neighbor Ising ring we want, and the natural setting for studying bulk properties of the TFIM.

3. Designing the quasi-adiabatic schedule

Section titled “3. Designing the quasi-adiabatic schedule”

The adiabatic theorem says that if we tune a Hamiltonian slowly enough, a system prepared in the ground state stays in the ground state throughout the sweep. "Slowly enough" means slow compared to the inverse square of the energy gap between the ground and first excited state.

Near a quantum critical point this gap closes, so a simple linear sweep is either wastefully slow everywhere, or not slow enough exactly where the gap is smallest. In our setting, it is right where we care about it: at the critical point at the end of the sweep.

To fix this, we use a tangent sweep: the detuning is swept from a large negative value δ0=−5 ΩR\delta_0 = -5\,\Omega_Rδ0​=−5ΩR​ up to the target δ\deltaδ following a tan⁡\tantan-shaped profile in time. This naturally slows the sweep down near the critical gap, where the system is most sensitive, and speeds it up everywhere else.

We start at δ0≪0\delta_0 \ll 0δ0​≪0 which is the ground state of the drive Hamiltonian, the product state ∣00…0⟩|00\dots0\rangle∣00…0⟩ (all atoms in the ground state ∣gg…g⟩|gg\dots g\rangle∣gg…g⟩). This is easy to prepare exactly, giving us a clean, known starting point for the adiabatic sweep.

The full schedule has two phases:

  1. Ramp-up (first frac_ramp of the total time T): the Rabi frequency Ω(t)\Omega(t)Ω(t) is smoothly turned on from 000 to ΩR\Omega_RΩR​, while the detuning stays fixed at δ0\delta_0δ0​ — this avoids a sudden jump in Ω\OmegaΩ, which would itself break adiabaticity.
  2. Detuning sweep (remaining time T*(1-frac_ramp)): Ω(t)=ΩR\Omega(t)=\Omega_RΩ(t)=ΩR​ is held constant, and the detuning follows the tangent profile from δ0\delta_0δ0​ toward Δ\DeltaΔ, slowing down as it crosses the critical point.

Before running anything, let's see the schedule. For a representative dimensionless time t=80t = 80t=80, program.draw() shows the two dimensionless control fields:

  • the Rabi amplitude Ω(t)\Omega(t)Ω(t) — a quick ramp, then held at ΩR\Omega_RΩR​;
  • the detuning δ(t)\delta(t)δ(t) — held at δ0\delta_0δ0​ during the ramp, then swept up to Δ\DeltaΔ.

Notice how the detuning flattens as it approaches the target: that is the tangent slowdown, spending proportionally more evolution time near the end of the sweep, where the many-body gap is smallest.

Everything above is defined in dimensionless units; compile_to maps the program onto the device's physical scale.

4. Computing the target state with exact diagonalization

Section titled “4. Computing the target state with exact diagonalization”

Before running the adiabatic preparation, we need a reference ground state to compare against. Since N=12N = 12N=12 is still small enough, we can build the full Rydberg Hamiltonian at the endpoint parameters (Ω,δ)(\Omega, \delta)(Ω,δ) and diagonalize it exactly.

The Rydberg Hamiltonian we diagonalize is

H(Ω,δ)=Ω2∑jσjx−δ∑jnj+∑i<jJij ninj H(\Omega, \delta) = \frac{\Omega}{2}\sum_j \sigma^x_j - \delta \sum_j n_j + \sum_{i<j} J_{ij}\, n_i n_j H(Ω,δ)=2Ω​j∑​σjx​−δj∑​nj​+i<j∑​Jij​ni​nj​

E_0 = -6.871569,  E_1 = -6.832049,  gap = 0.039520

Why a tangent sweep? The adiabatic cost is governed by the instantaneous gap along the path we follow. Keeping Ω=ΩR\Omega=\Omega_RΩ=ΩR​ fixed and sweeping the detuning from δ0\delta_0δ0​ to Δ\DeltaΔ, we can diagonalize H(ΩR,δ)H(\Omega_R,\delta)H(ΩR​,δ) at each step and track the gap directly. It is large at the start (deep in the far-detuned regime, where the ground state is the trivial product state) and shrinks as we approach the critical endpoint: which is precisely where the tangent schedule slows down.

In the plot below we overlay the gap (left axis) and the detuning pulse δ\deltaδ itself (right axis) against the sweep progress s∝ts\propto ts∝t. The pulse flattens, i.e. where the sweep spends more time, is exactly in the shaded region where the gap is smallest.

How close is the Rydberg target to the ideal TFIM critical state?

Section titled “How close is the Rydberg target to the ideal TFIM critical state?”

The state we prepare is the ground state of the Rydberg Hamiltonian at the endpoint parameters — not, exactly, the ground state of the clean nearest-neighbor TFIM. It is worth quantifying the difference once, as a sanity check on the mapping.

We build the ideal periodic TFIM on the same ring,

HTFIM=∑iσizσi+1z+h∑iσix,σN+1z≡σ1z, H_{\text{TFIM}} = \sum_i \sigma^z_i\sigma^z_{i+1} + h\sum_i \sigma^x_i, \qquad \sigma^z_{N+1}\equiv\sigma^z_1, HTFIM​=i∑​σiz​σi+1z​+hi∑​σix​,σN+1z​≡σ1z​,

and compute the overlap of its ground state with our Rydberg target. For our periodic ring the two are remarkably close: the overlap comes out around 0.9970.9970.997. The tiny residual gap below 111 is the price of realizing an idealized spin model on real Rydberg hardware, the Rydberg Hamiltonian carries long-range interaction tails beyond nearest neighbors and a residual local field.

5. Running the adiabatic state preparation

Section titled “5. Running the adiabatic state preparation”

We now run the actual time-evolution under the quasi-adiabatic schedule using the emu_sv backend (exact state-vector propagation).

A note on time. qoolqit programs live in dimensionless units: the drive duration ttt is measured relative to the timescale on which the interactions build up correlations, so t∼1t \sim 1t∼1 is "one interaction time" and t≫1t \gg 1t≫1 is a slow, near-adiabatic evolution. This is the natural knob for the adiabatic theorem: the slower the sweep compared to the interaction timescale, the better we track the instantaneous ground state through the small gap.

We sweep the dimensionless total time ttt directly, letting the compiler map each value onto the device; no hardware duration needs to be specified by hand.

For each ttt we request three observables: (i) the occupation ⟨ni⟩\langle n_i\rangle⟨ni​⟩, (ii) the correlation matrix ⟨ninj⟩\langle n_i n_j\rangle⟨ni​nj​⟩, and (iii) the fidelity against the ED ground state.

6. Conclusion

Section titled “6. Conclusion”

We prepared the critical ground state of the 1D Transverse-Field Ising Model on a ring of 12 atoms using a quasi-adiabatic tangent sweep in qoolqit's Rydberg analog model. Sweeping the dimensionless evolution time ttt, the fidelity with the ED target rises toward 111 as the sweep becomes slower and saturates once ttt is comfortably larger than the interaction timescale, even across the small critical gap.
