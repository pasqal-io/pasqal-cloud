Efficient estimation techniques for Variational Quantum Simulation

Introduction

Section titled “Introduction”

\newcommand{\ket}[1]{\left|#1\right>} \newcommand{\bra}[1]{\left<#1\right|} This notebook’s purpose is to introduce the concept of classical shadow estimation, as well as its use in VQS (Variational Quantum Simulation). This technique, introduced in this article by Huang, Kueng and Preskill (external), is used for efficiently estimating multiple observables, and is extremely powerful in that regard, asymptotically reaching theoretical lower bounds of quantum information theory regarding the number of required samples of a given state for estimation (see here for details (external)).

The primary goal of this notebook is to estimate the groundstate energy of the H2H_2H2​ molecule, using a VQS. We will first implement the method of random classical shadows in Python. Then, we’ll introduce its derandomized counterpart, which is particularly useful in our setting. We’ll finally describe the VQS, and benchmark the estimation methods we introduced for computing the molecule’s energy. This notebook draws some inspiration from this PennyLane Jupyter notebook (external) on quantum machine learning and classical shadows.

Random classical shadows

Section titled “Random classical shadows”

Main ideas and implementation

Section titled “Main ideas and implementation”

Classical shadow estimation relies on the fact that for a particular choice of measurement, we can efficiently store snapshots of the state that contain enough information to accurately predict linear functions of observables.

Let us consider an nnn-qubit quantum state ρ\rhoρ (prepared by a pulse sequence) and apply a random unitary UUU to the state:

ρ→UρU†.\rho \to U \rho U^\dagger.ρ→UρU†.

Next, we measure in the computational basis and obtain a bit string of outcomes ∣b⟩=∣0011…10⟩|b\rangle = |0011\ldots10\rangle∣b⟩=∣0011…10⟩. If the unitaries UUU are chosen at random from a particular ensemble, then we can store the reverse operation U†∣b⟩⟨b∣UU^\dagger |b\rangle\langle b| UU†∣b⟩⟨b∣U efficiently in classical memory. We call this a snapshot of the state. Moreover, we can view the average over these snapshots as a measurement channel:

E[U†∣b⟩⟨b∣U]=M(ρ).\mathbb{E}\left[U^\dagger |b\rangle\langle b| U\right] = \mathcal{M}(\rho).E[U†∣b⟩⟨b∣U]=M(ρ).

We restrict ourselves to unitary ensembles that define a tomographically complete set of measurements (i.e M\mathcal{M}M is invertible), therefore :

ρ=E[M−1(U†∣b⟩⟨b∣U)].\rho = \mathbb{E}\left[\mathcal{M}^{-1}\left(U^\dagger |b\rangle\langle b| U \right)\right].ρ=E[M−1(U†∣b⟩⟨b∣U)].

If we apply the procedure outlined above NNN times, then the collection of inverted snapshots is what we call the classical shadow

S(ρ,N)={ρ^1=M−1(U1†∣b1⟩⟨b1∣U1),…,ρ^N=M−1(UN†∣bN⟩⟨bN∣UN)}.S(\rho,N) = \left\{\hat{\rho}_1= \mathcal{M}^{-1}\left(U_1^\dagger |b_1\rangle\langle b_1| U_1 \right) ,\ldots, \hat{\rho}_N= \mathcal{M}^{-1}\left(U_N^\dagger |b_N\rangle\langle b_N| U_N \right) \right\}.S(ρ,N)={ρ^​1​=M−1(U1†​∣b1​⟩⟨b1​∣U1​),…,ρ^​N​=M−1(UN†​∣bN​⟩⟨bN​∣UN​)}.

Since the shadow approximates ρ\rhoρ, we can now estimate any observable with the empirical mean:

⟨O⟩=1N∑iTrρ^iO.\langle O \rangle = \frac{1}{N}\sum_i \text{Tr}{\hat{\rho}_i O}.⟨O⟩=N1​i∑​Trρ^​i​O.

We will be using a median-of-means procedure in practice.

We start by defining several useful quantities, such as the unitary matrices associated with Pauli measurements : the Hadamard matrix, change of basis from {∣0⟩,∣1⟩}\{\ket{0}, \ket{1}\}{∣0⟩,∣1⟩} to the eigenbasis of σX\sigma_XσX​, {∣+⟩,∣−⟩}\{\ket{+}, \ket{-}\}{∣+⟩,∣−⟩}, and its σY,σZ\sigma_Y, \sigma_ZσY​,σZ​ counterparts. We will then draw randomly from this tomographically complete set of 333 unitaries.

Note that we will need 444 qubits for our VQS problem : we will explain the mapping from the molecule to qubits later.

We first define a function that spits out a random bitstring sampled from a given density matrix.

We will need to compute the number of shadows needed given :

  • A list of observables oio_ioi​

  • Desired precision on expectation values ϵ\epsilonϵ : if o~i\tilde{o}_io~i​ is the estimated expectation value for observable oio_ioi​, we wish for ∣Tr(oiρ)−o~i∣≤ϵ|Tr(o_i \rho) - \tilde{o}_i| \leq \epsilon∣Tr(oi​ρ)−o~i​∣≤ϵ

Next, we design a function that returns snapshots (bitstrings) of the rotated state as well as the sampled unitaries used to rotate the state ρ\rhoρ.

We then reconstruct an estimate of the quantum state from the sampled bitstrings, using the inverse quantum channel M−1\mathcal{M}^{-1}M−1 defined above. In the particular case of Pauli measurements, we can actually compute the inverse channel :

M−1=⊗i=1n(3Ui∣bi⟩⟨bi∣Ui†−12)\mathcal{M}^{-1} = \otimes_{i=1}^n (3 U_i \ket{b_i}\bra{b_i} U^\dagger_i - \mathbb{1}_2)M−1=⊗i=1n​(3Ui​∣bi​⟩⟨bi​∣Ui†​−12​)

We finally write a median of means procedure. We feed it an observable, the list of snapshots computed above and the number of blocks needed. It returns the median of the means of the observable acting on the snapshots in each block.

Derandomized Paulis

Section titled “Derandomized Paulis”

Derandomization Algorithm

Section titled “Derandomization Algorithm”

Randomized classical shadows are useful when dealing with low-weight, general observables. However, suppose, as is the case when estimating the Hamiltonian of the H2H_2H2​ molecule written as a sum of Pauli strings, that we’re dealing with Pauli observables of varying weights. In this setting, choosing wisely each Pauli measurement instead of randomly drawing a basis is particularly useful : indeed, say one wants to measure observable σx1⊗σx2⊗⋯⊗σxn\sigma_x^1 \otimes \sigma_x^2 \otimes \dots \otimes \sigma_x^nσx1​⊗σx2​⊗⋯⊗σxn​. Using random rotations in each Pauli X,YX,YX,Y or ZZZ basis and projection in the ZZZ (computational) basis, there is a probability 13n\frac{1}{3^n}3n1​ to get each measurement basis right (i.e. rotate the system using the Hadamard matrix). This is extremely unlikely and unefficient as the number of qubits goes up. Huang et al (external) outline an interesting greedy algorithm used for choosing suitable measurement bases for the efficient estimation of LLL n−n-n−qubit Pauli strings, {Oi}\{O_i\}{Oi​}.

Feeding these observables and chosen Pauli measurements {P_i} as input, the algorithm aims at optimizing a certain cost function. This function, labeled Confϵ(Oi,Pj)Conf_\epsilon(O_i, P_j)Confϵ​(Oi​,Pj​) is such that, if Confϵ(Oi,Pj)≤δ2Conf_\epsilon(O_i, P_j) \leq \frac{\delta}{2}Confϵ​(Oi​,Pj​)≤2δ​, then the empirical averages ωl~\tilde{\omega_l}ωl​~​ of each Pauli observable OlO_lOl​ will be ϵ\epsilonϵ-close to its true average Tr(ρOl)Tr(\rho O_l)Tr(ρOl​) with probability 1−δ1-\delta1−δ.

In order to implement this cost function, we first need to design two auxiliary functions. The first one decides if a given Pauli measurement ppp is compatible with (“hits”) a Pauli observable ooo. This means that each time ooo acts non-trivially on a qubit qiq_iqi​ with Pauli matrix σ∈{σX,σY,σZ},σ≠1\sigma \in \{\sigma_X, \sigma_Y, \sigma_Z\}, \sigma \neq \mathbb{1}σ∈{σX​,σY​,σZ​},σ=1, ppp acts on qiq_iqi​ with σ\sigmaσ. We denote it by o▹po \triangleright po▹p.

The second function simply computes the number of qubits observable ooo acts non-trivially upon.

We now implement the conditioned cost function using these auxiliary functions. We call it “conditioned”, since we feed it only the first m×n+km \times n + km×n+k single-qubit Pauli measurements, and average over the others, not yet determined ones.

Finally, we design a simple greedy algorithm which purpose is to minimize this conditioned cost function, choosing one single-qubit Pauli at a time.

Variational Quantum Simulation for the H2H_2H2​ molecule

Section titled “Variational Quantum Simulation for the H2H_2H2​ molecule”

The main problem with usual variational classical algorithms, the classical counterparts of VQS, is computing the value of the 2n×2n2^n \times 2^n2n×2n matrix on the output state vector ⟨ψ∣H∣ψ⟩\bra{\psi}H\ket{\psi}⟨ψ∣H∣ψ⟩ after each loop of the algorithm, which grows exponentially in the size of the system. The purpose of VQS algorithms is to offer a solution which time complexity only grows polynomially, thanks to reading all the important properties on the quantum state. Therefore, we need accurate and efficient methods to estimate these properties, which we’ll present afterwards.

For now, let’s focus on what makes a VQS algorithm, specifically for computing the groundstate energy of the H2H_2H2​ molecule.

Quantum Loop (VQS)

The quantum part will do the exploration in Hilbert space, according to a certain set of parameters θi,τj\theta_i, \tau_jθi​,τj​, and the classical part will find the optimal parameters given the value of the energy after each loop. Randomized measurements

Section titled “Randomized measurements”

We now consider the real-life problem where we don’t have access to the exact value ⟨Ψ(θi,τj)∣HJW∣Ψ(θi,τj)⟩\bra{\Psi(\theta_i, \tau_j)} H_{JW} \ket{\Psi(\theta_i, \tau_j)}⟨Ψ(θi​,τj​)∣HJW​∣Ψ(θi​,τj​)⟩. It can be estimated with classical shadows. We modify the quantum loop to add classical shadow estimation of the several Pauli strings making up the HJWH_{JW}HJW​ Hamiltonian : this is the perfect setting to do so, because we have multiple Pauli strings and most of them have low weight.

[<matplotlib.lines.Line2D at 0x1fad2d59c50>]

As could be expected, the estimation can be worse than what we got before : we added both randomness and sampling issues to the problem. Raising shadow size will allow more and more precise results. However, it can also be closer to the exact value for the same reasons.

Derandomized measurements

Section titled “Derandomized measurements”

Finally, we try out the derandomized measurements method. To implement this one, we need to decompose the Hamiltonian into individual Pauli strings, rather than group them when they share the same leading coefficient as we did before, as it reduced the number of estimations.

Then, we ask the derandomization algorithm to return 606060 suitable Pauli measurements regarding our input Pauli observables. 606060 is arbitrary, but is small enough that the algorithm runs quickly and large enough that it gives good results.

ZZZZ measurements : 18, XXYY measurements : 11, YXXY measurements : 11, XYYX measurements : 10, YYXX measurements : 10 : total = 60 measurements

As we can see, since all Pauli observables appearing in the Jordan-Wigner Hamiltonian involving the ZZZ-basis never involve another basis, we find that it is always worth it to measure Pauli string ZZZZZZZZZZZZ rather than ZZZXZZZXZZZX, or ZYZZZYZZZYZZ, etc. This is a sign that our cost function is doing its job !

[<matplotlib.lines.Line2D at 0x1fad32d8b10>]

We consistently obtain accurate results using this derandomized technique, and we obtain them far quicker than when dealing with randomized classical shadows. For roughly the same number of samples (∼60\sim 60∼60 for each method, be it for shadow size or number of measurements), we experience much less computing time using the derandomized method. This was to be expected : by restricting the observables to Pauli strings, we allow for efficient estimation that can be easily computed in O(M×n)O(M\times n)O(M×n), as well as remove randomness problematic with higher-weight observables (such as YYXXYYXXYYXX or YXXYYXXYYXXY).

Note that we obtain 2%2\%2% accuracy after about 505050 Z−Z-Z− basis measurements (fluorescence) of the output state, rotated before each sampling in the bases returned by the derandomization algorithm.
