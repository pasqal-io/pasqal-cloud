Simulation of XYZ spin models using Floquet engineering in XY mode

In this notebook, we will reproduce some results of “Microwave-engineering of programmable XXZ Hamiltonians in arrays of Rydberg atoms”, P. Scholl, et. al., https://arxiv.org/pdf/2107.14459.pdf (external).

Floquet Engineering on two atoms

Section titled “Floquet Engineering on two atoms”

We start by considering the dynamics of two interacting atoms under HXXZH_{XXZ}HXXZ​. To demonstrate the dynamically tunable aspect of the microwave engineering, we change the Hamiltonian during the evolution of the system. More specifically, we start from ∣→→⟩y|\rightarrow \rightarrow \rangle_y∣→→⟩y​, let the atoms evolve under HXXH_{XX}HXX​ and apply a microwave pulse sequence between 0.9μs0.9\mu s0.9μs and 1.2μs1.2\mu s1.2μs only.

During that period, the total y-magnetization ⟨σ1y+σ2y⟩\langle \sigma^y_1 + \sigma^y_2 \rangle⟨σ1y​+σ2y​⟩ is expected to be frozen, as this quantity commutes with HXXXH_{XXX}HXXX​.

Note that one cannot directly measure off diagonal elements of the density matrix experimentally. To be able to measure ⟨σ1y+σ2y⟩\langle \sigma^y_1 + \sigma^y_2 \rangle⟨σ1y​+σ2y​⟩, one would need to first apply a rotation on the atoms (equivalent to changing the basis) and then measure the population.

Domain-wall dynamics

Section titled “Domain-wall dynamics”

Now, we will look at the dynamics of the system under HXX2ZH_{XX2Z}HXX2Z​ when starting in a Domain-Wall (DW) state ∣ψ0⟩=∣↑↑↑↑↑↓↓↓↓↓⟩≡∣0000011111⟩|\psi_0\rangle = |\uparrow \uparrow \uparrow \uparrow \uparrow \downarrow \downarrow \downarrow \downarrow \downarrow\rangle \equiv |0000011111\rangle∣ψ0​⟩=∣↑↑↑↑↑↓↓↓↓↓⟩≡∣0000011111⟩, for two distinct geometries : open boundary conditions (OBC) and periodic boundary conditions (PBC). In the case of HXX2ZH_{XX2Z}HXX2Z​, only 2 pulses per Floquet cycle are required, as the XXX and −X-X−X pulses cancel out.

In the experiment, all the atoms start in the same initial state. In order to create a domain-wall state, one must apply a π\piπ-pulse on only half of the atoms. On the hardware, this can be done by using a Spatial Light Modulator which imprints a specific phase pattern on a laser beam. This results in a set of focused laser beams in the atomic plane, whose geometry corresponds to the subset of sites to address, preventing the addressed atoms from interacting with the global microwave pulse due to a shift in energy.

This feature is implemented in Pulser. For implementing this, we need to define a π\piπ-pulse, and the list of indices of the atoms we want to mask.

Let’s plot the evolution of the magnetization ⟨σjz⟩\langle \sigma^z_j \rangle⟨σjz​⟩ in time for all the sites jjj.

We see that the magnetization profiles look rather different for OBC and PBC. It seems that the initial DW melts in the case of PBC. In fact, the decrease of ∣⟨σjz⟩∣|\langle \sigma^z_j \rangle|∣⟨σjz​⟩∣ for all sites is due to a delocalization of the DW along the circle. This delocalization can be more apparent when looking at correlations. More specifically, we see on the plot below that the number of spin flips between consecutive atoms along the circle, ⟨Nflip⟩=1/2∑j(1−⟨σjzσj+1z⟩)\langle N_{flip} \rangle=1/2\sum_j(1-\langle \sigma_j^z \sigma_{j+1}^z\rangle)⟨Nflip​⟩=1/2∑j​(1−⟨σjz​σj+1z​⟩), remains quite low during the dynamics for both OBC (red) and PBC (blue), while it should tend to Nat/2=5N_{at}/2=5Nat​/2=5 for randomly distributed spins.
