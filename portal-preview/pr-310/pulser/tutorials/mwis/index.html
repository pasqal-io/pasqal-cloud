QAA to solve a MWIS problem

Advanced Concepts used in this tutorial:

  • Detuning Map and Detuning Map Modulator;

  • Virtual Device and the MockDevice;

Introduction

Section titled “Introduction”

In this tutorial, we illustrate how to solve a Maximally Weighted Independent Set (MWIS) problem using an ensemble of Rydberg atoms in analog mode.

MWIS arise in many applications, including resource allocation, scheduling and staffing problems, error-correcting coding, complex system analysis and optimization, logistics and transportation, communication networks…

In the MWIS problem, we consider an undirected graph with nodes and edges where each node is associated with a positive weight. The problem is to find a maximum weighted independent set, i.e., select a set of nodes in graph where:

  • there is no edge between any pair of selected nodes.

  • the sum of the weights of the nodes for this set is maximised.

Note:

If all the weights of the nodes are the same, then this problem is called the Maximally Independent Set (MIS).

Example of an MWIS

Section titled “Example of an MWIS”

Suppose we are given the following graph:

It is an undirected graph with:

  • 4 nodes 0, 1, 2 and 3;

  • edges between nodes 0-1, 0-2, 0-3 and 3-2;

  • a weight of 2 assigned to nodes 1 and 2, and a weight of 0 assigned to nodes 0 and 3.

There are two Maximally Independent Set (sets of nodes with no edge between them):

  • {1, 2}: the sum of the weights of the nodes is 4.

  • {1, 3}: the sum of the weights of the nodes is 2.

So the MWIS of this graph is {1, 2}.

Solving the MWIS with Pulser

Section titled “Solving the MWIS with Pulser”

Let’s recall that Pulser enables you to program a Weighted Analog Ising Hamiltonian HQH_QHQ​:

HQℏ(t)=∑k=1N(Ω(t)2e−iϕ(t)∣g⟩⟨r∣k+Ω(t)2eiϕ(t)∣r⟩⟨g∣k−(δ(t)+ϵkδDMM(t))∣r⟩⟨r∣k+∑j<kC6ℏRkj6n^kn^j)\frac{H_Q}{\hbar}(t) = \sum_{k=1}^N \left (\frac{\Omega(t)}{2} e^{-i\phi(t)} |g\rangle\langle r|_k + \frac{\Omega(t)}{2} e^{i\phi(t)} |r\rangle\langle g|_k - (\delta(t)\mathbf{+\epsilon_k\delta_{DMM}(t)}) |r\rangle\langle r|_k + \sum_{j<k}\frac{C_6}{\hbar R_{kj}^6} \hat{n}_k \hat{n}_j \right)ℏHQ​​(t)=k=1∑N​​2Ω(t)​e−iϕ(t)∣g⟩⟨r∣k​+2Ω(t)​eiϕ(t)∣r⟩⟨g∣k​−(δ(t)+ϵk​δDMM​(t))∣r⟩⟨r∣k​+j<k∑​ℏRkj6​C6​​n^k​n^j​​

The first idea is to encode the off-diagonal terms of QQQ by using the Rydberg interaction between atoms:

[C6ℏRkj6]1≤k,j≤N↔Qoff−diagonal\left[\frac{C_6}{\hbar R_{kj}^6}\right]_{1\leq k, j \leq N}\leftrightarrow Q_{off-diagonal}[ℏRkj6​C6​​]1≤k,j≤N​↔Qoff−diagonal​

Since the Rydberg interaction depends on the pairwise distance between atoms kkk and jjj, RkjR_{kj}Rkj​, this will define the Register of atoms to use in the computation.

Note:

We can make this mapping because our off-diagonal terms are positive as well.

The second idea is to encode the diagonal terms of QQQ by using the weights of the Detuning Map ϵk↔Qkk\epsilon_k \leftrightarrow Q_{kk}ϵk​↔Qkk​ for 1≤k≤N1\le k\le N1≤k≤N.

Finally, the third idea is to find the optimal solution of the QUBO by preparing the ground-state of HQH_QHQ​ and outputing the optimal bitstrings. There are multiple approaches to prepare the ground-state of an Hamiltonian, we will here use the Quantum Adiabatic Algorithm (QAA), that will define Ω(t)\Omega(t)Ω(t), δ(t)\delta(t)δ(t), δDMM(t)\delta_{DMM}(t)δDMM​(t).

One Detuning Map Modulator

Section titled “One Detuning Map Modulator”

The second channel needed to implement the Weighted Analog Ising Hamiltonian HQH_QHQ​ is the DMM channel, that adds the terms −∑1≤k≤NϵkδDMM(t)∣r⟩⟨r∣k-\sum_{1\le k\le N}\mathbf{\epsilon_k\delta_{DMM}(t)} |r\rangle\langle r|_k−∑1≤k≤N​ϵk​δDMM​(t)∣r⟩⟨r∣k​ to the Ising Hamiltonian.

When configuring the DMM channel, we need to provide it a DetuningMap, which assigns to each atom in the Register a weight [ϵk]1≤k≤N\left[\epsilon_k\right]_{1\le k \le N}[ϵk​]1≤k≤N​.

Using the diagonal of the matrix :math:`Q`, we decide that:

  • the atoms that have the highest weight will not experience any additionnal detuning δDMM\delta_{DMM}δDMM​ (we want to favor the solution for the maximal weights).

  • each of the other atoms will experience an additionnal detuning, that is proportional to the difference between the highest weight and their weight.

  • the atoms that have the lowest weight will not experience any additionnal detuning δDMM\delta_{DMM}δDMM​.

  • each of the other atoms will experience an additionnal detuning, that is proportional to the difference between their weight and the lowest weight.

4. Add the Pulses

Section titled “4. Add the Pulses”

The idea behind the adiabatic algorithm (see Albash, Lidar, 2018 (external)) is to slowly evolve the system from an easy-to-prepare groundstate to the groundstate of HQH_QHQ​. If done slowly enough, the system of atoms stays in the instantaneous ground-state.

In our case, we continuously vary the parameters Ω(t),Δk(t)=δ(t)+ϵkδDMM(t)\Omega(t), \Delta_k(t)=\delta(t)+\epsilon_k \delta_{DMM}(t)Ω(t),Δk​(t)=δ(t)+ϵk​δDMM​(t) (for 1≤k≤N1\le k\le N1≤k≤N) in time, starting with Ω(0)=0,Δk(0)≤0\Omega(0)=0, \Delta_k(0)\le0Ω(0)=0,Δk​(0)≤0 (for all kkk) and ending with Ω(0)=0,Δk≥0\Omega(0)=0, \Delta_k\ge0Ω(0)=0,Δk​≥0 (for all kkk). The ground-state of H(0)H(0)H(0) corresponds to the initial state ∣gggg⟩|gggg\rangle∣gggg⟩ and the ground-state of H(tf)H(t_f)H(tf​) corresponds to the ground-state of HQH_QHQ​.

To favor the final ground-state to be in an optimal solution of the MWIS, we will add a penalty detuning to the qubits associated with the lowest weights by adding a constant local detuning δDMM(t)=−δf\delta_{DMM}(t) = - \delta_fδDMM​(t)=−δf​.

To ensure that we are not exciting the system to states that are too excited, we keep Ω∈[0,Ωmax]\Omega \in [0, \Omega_{\text{max}}]Ω∈[0,Ωmax​], and choose Ωmax\Omega_{\text{max}}Ωmax​ as the maximum energy of two non-connected nodes to ensures that the adiabatic path is efficient.

The outcome is effectively 0110, which is the optimal solution for the MWIS problem on the graph !

To go further:

  • The heuristic we are using here to define the values of Ω\OmegaΩ, δ\deltaδ, δDMM\delta_{DMM}δDMM​ along time works well in this case. You will surely have to adapt these values if you change the graph (the matrix QQQ). To tune them automatically, you can use an optimization procedure to find the sequence maximizing your cost function f(z)f(z)f(z). An example of an optimization procedure is presented in this tutorial (for a different cost function).

  • This notebook can be adapted to solve a QUBO with diagonal terms, only the definition of the detuning map has to be changed.
