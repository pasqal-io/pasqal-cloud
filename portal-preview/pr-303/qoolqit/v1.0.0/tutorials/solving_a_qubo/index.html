Solving a basic QUBO problem

A QUBO instance on NNN variables consists in a symmetric matrix QQQ of size N×NN\times NN×N, and solving a QUBO problems means to find the bitstring z=(z1,...,zN)∈{0,1}Nz=(z_1,...,z_N)\in\{0, 1\}^Nz=(z1​,...,zN​)∈{0,1}N that minimizes the quantity

f(z)=zTQz f(z) = z^TQz f(z)=zTQz

Problem generation

Section titled “Problem generation”

Many real-world problems can be mapped to a QUBO problem, which means to create the matrix QQQ that encodes the problem to solve. For the purpose of this tutorial we assume this task has already been performed and we are given the matrix QQQ, such as the one below:

QUBO problems are scale-invariant, and so we can work with the normalized matrix Q~=Q/max(Q)\tilde{Q}=Q/\text{max}(Q)Q~​=Q/max(Q) instead.

Before showing how to solve this QUBO instance in the Rydberg analog model, we can compute the optimal solutions classically to compare. For that we do a brute force cost calculation over all possible bitstrings, which scales exponentially with the number of variables. This is only possible because we are dealing with a small QUBO.

Problem embedding

Section titled “Problem embedding”

To embed the QUBO problem in the Rydberg analog model, we can directly use a matrix embedding technique like the InteractionEmbedder. You can read more about it in the available embedders contents page.

The InteractionEmbedder maps a matrix to a graph with node coordinates, from which we can directly instantiate a qubit register later.

Writing a quantum program

Section titled “Writing a quantum program”

To solve this QUBO instance, we are going to use an annealing schedule where we raise the amplitude to some value Ω\OmegaΩ while sweeping the detuning from δi\delta_iδi​ to δf\delta_fδf​. We pick the Ω\OmegaΩ as the median of the values of QQQ, and define δi\delta_iδi​ and δf\delta_fδf​ as ±2Ω\pm 2 \Omega±2Ω. A long enough duration should allow the annealing schedule to be successful.
