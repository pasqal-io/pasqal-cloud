Solving a QUBO problem

A QUBO instance on NNN variables consists of a symmetric matrix QQQ of size N×NN\times NN×N.

Solving a QUBO problem means to find the bitstring z=(z1,...,zN)∈{0,1}Nz=(z_1,...,z_N)\in \{0, 1\}^Nz=(z1​,...,zN​)∈{0,1}N that minimizes the quantity

f(z)=zTQz=∑iQiizi+∑i<jQijzizj,zi∈{0,1}. f(z) = z^TQz= \sum_i Q_{ii} z_i + \sum_{i<j} Q_{ij} z_i z_j, \quad z_i \in \{0,1\}. f(z)=zTQz=i∑​Qii​zi​+i<j∑​Qij​zi​zj​,zi​∈{0,1}.

Problem Formulation in Rydberg Hamiltonian

Section titled “Problem Formulation in Rydberg Hamiltonian”

To use a Rydberg Analog model, we need to map the QUBO problem onto the Rydberg Hamiltonian.

This is achieved by identifying the binary variables with atomic occupations zi=ni z_i = n_i zi​=ni​

where $ n_i \in {0,1} $ denotes whether atom iii is in the Rydberg state.

The effective Hamiltonian in the classical (diagonal Ω~=0\tilde{\Omega}=0Ω~=0) limit of the driven Rydberg system can be written as

H=−∑iδ~ini+∑i<jJ~ijninj, H = - \sum_i \tilde{\delta}_i n_i + \sum_{i<j} \tilde{J}_{ij} n_i n_j, H=−i∑​δ~i​ni​+i<j∑​J~ij​ni​nj​,

where $ \tilde{\delta} $ is the local detuning and $ J_{ij}=1/r_{ij}^6 $ is the interaction energy between atoms iii and jjj. By direct comparison, we obtain the mapping

Qii  ⟷  −δ~i,Qij  ⟷  J~ij. Q_{ii} \;\longleftrightarrow\; - \tilde{\delta}_i, \qquad Q_{ij} \;\longleftrightarrow\; \tilde{J}_{ij}. Qii​⟷−δ~i​,Qij​⟷J~ij​.

In this way, by tuning the interaction strengths between atoms (e.g., via their spatial separation) we can match the QUBO coefficients, while the diagonal terms QiiQ_{ii}Qii​ map to the local detunings. Under this correspondence, the ground state of the Rydberg Hamiltonian minimizes HHH and therefore encodes the optimal solution of the original QUBO problem.

Section titled “Intensity of Detuning and Amplitude”

We have to start from a negative value of the detuning (compatible with the initial state ∣0⟩⊗N{\left|0\right\rangle}^{\otimes N}∣0⟩⊗N) - δ~(t=T)=−diag(Q)\tilde{\delta}(t=T)=-\mathrm{diag}(Q)δ~(t=T)=−diag(Q). Amplitude Ω~\tilde{\Omega}Ω~: - max⁡Ω~=median(off_diag_Q)\max{\tilde{\Omega}}=\mathrm{median}(\mathrm{off\_diag\_Q})maxΩ~=median(off_diag_Q).

NOTE: The value of Ω~\tilde{\Omega}Ω~ could be, in principle, optimized for each given QUBO but a good handwavy value is setting it as the median of the off-diagonal elements of the QUBO.

Time Duration

Section titled “Time Duration”

We then define the shape and duration of the schedule. In QoolQit, t~\tilde{t}t~ measures evolution time relative to the timescale on which interactions generate correlations.

Roughly speaking, a time t~∼1\tilde{t} \sim 1t~∼1 is enough for nearest-neighbor sites to begin developing correlations. More generally, t~∼n\tilde{t} \sim nt~∼n can be interpreted as the timescale on which correlations may have propagated over a distance of order nnn lattice spacings.

This makes dimensionless time a convenient, geometry-independent way to describe how long the system evolves relative to its intrinsic interaction dynamics.

Regime Condition Intuition
Short time t~≪1\tilde{t} \ll 1t~≪1 Evolution is too brief for interactions to significantly build up correlations
Intermediate time t~∼1\tilde{t} \sim 1t~∼1 Interactions begin to visibly affect the dynamics; nearest-neighbor correlations can emerge
Long time t~≫1\tilde{t} \gg 1t~≫1 Correlations and many-body interaction effects have had time to spread across the system
