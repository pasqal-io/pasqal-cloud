Control-Z Gate Sequence

Introduction

Section titled “Introduction”

In this tutorial we show how to prepare the pulse sequence that generates a Controlled - Z gate. We will prepare our state with atoms in any of the “digital” states that we shall call ∣g⟩|g\rangle∣g⟩ and ∣h⟩|h \rangle∣h⟩ ( for “ground” and “hyperfine”, respectively). Then we will use the Rydberg blockade effect to create the logic gate. The levels that each atom can take are the following:

1. Loading the Register on a Device

Section titled “1. Loading the Register on a Device”

Defining an atom register can simply be done by choosing one of the predetermined shapes included in the Register class. We can also construct a dictionary with specific labels for each atom. The atoms must lie inside the Rydberg blockade radius RbR_bRb​, which we will characterize by

ℏΩRabiMax∼Uij=C6Rb6,\hbar \Omega^{\text{Max}}_{\text{Rabi}} \sim U_{ij} = \frac{C_6}{R_{b}^6},ℏΩRabiMax​∼Uij​=Rb6​C6​​,

where the coefficient C6C_6C6​ determines the strength of the interaction (C6/ℏ≈5008C_6/\hbar \approx 5008C6​/ℏ≈5008 GHz.μm6\mu m^6μm6). We can obtain the corresponding Rydberg blockade radius from a given ΩRabimax\Omega_{\text{Rabi}}^{\text{max}}ΩRabimax​ using the rydberg_blockade_radius() method from DigitalAnalogDevice. For the pulses in this tutorial, ΩRabiMax\Omega^{\text{Max}}_{\text{Rabi}}ΩRabiMax​ is below 2π×102\pi \times 102π×10 Mhz so:

Thus, we place our atoms at relative distances below 555 µm, therefore ensuring we are inside the Rydberg blockade volume.
