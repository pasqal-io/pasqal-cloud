RebatchFilters

Bases: BaseJobFilters

Class to provide filters for querying jobs to re-create.

Setting a value for any attribute of this class will add a filter to the query.

When using several filters at the same time, the API will return elements who pass all filters at the same time: - If the filter value is a single element, the API will return jobs whose attribute matches the provided value. - If the filter value is a list, the API will return jobs whose value for this attribute is contained in that list.

ATTRIBUTE DESCRIPTION
id

Filter by job IDs

TYPE: Optional[Union[List[Union[UUID, str]], Union[UUID, str]]]

status

Filter by job statuses,

TYPE: Optional[Union[List[JobStatus], JobStatus]]

min_runs

Minimum number of runs.

TYPE: Optional[int]

max_runs

Maximum number of runs.

TYPE: Optional[int]

start_date

Jobs created at or after this datetime.

TYPE: Optional[datetime]

end_date

Jobs created at or before this datetime.

TYPE: Optional[datetime]
